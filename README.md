# Cryo-Launcher
## About
We made a Snowball launcher that has servos which do the spinning of the motors and the only human input that is needed is for a bit of creating to create the shaved ice for the snowball. Once shaved ice is created, it is put into a mold that makes a snowball and then you can put it into the launcher and shoot it off into the sky!
## Why make this.
This Cryo-launcher was made for the Hack Club Stasis hackathon, which asked us to choose a "stash item," which is a special ingrediant that has to be integrated into the product. Alot of the the parts are 3D printed and parts are very small so it is not a magor inconvenice, but if you use PETG it would be food-safe, which is recommended, if not this is sole for the fun and not for consumption.
